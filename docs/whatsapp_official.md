# Alternatif Desain WhatsApp Business Platform

Pada alternatif desain ini, sistem dianalisis apabila menggunakan
WhatsApp Business Platform sebagai media komunikasi resmi.
Integrasi dilakukan melalui mekanisme API dan webhook.

Tahapan integrasi meliputi:
1. Pembuatan akun WhatsApp Business.
2. Pendaftaran WhatsApp Business Platform.
3. Konfigurasi access token.
4. Pengaturan webhook untuk menerima pesan.
5. Penggunaan template message untuk komunikasi awal.
